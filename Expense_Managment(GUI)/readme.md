# 🧾 Expense Management System — GUI Edition

A clean, modern **Graphical User Interface (GUI)** application for tracking and storing expenses with automatic serial numbering and **MS Excel file saving**.  
Designed for simplicity, accuracy, and a smooth workflow.

---

 All expenses are saved to <b>expenses.xlsx</b> with each entry written to a new row. 
</div>
<h2>Workflow</h2>

1. Launch the application
2. Previous data loads from MS Excel file
3. User enters expense details
4. Input validation occurs
5. New Serial ID is generated
6. Entry appears in the GUI table
7. Data is appended to expenses.xlsx
8. User continues adding or reviewing expenses
9. App closes safely — all data remains saved
