## 📌 Project Description

This project is a GUI-based **Data Entry Form** designed to take user input and store it for later use. It is styled to look clean, minimal, and beginner-friendly, making it a great example for students learning Tkinter.

The form contains fields such as:

* Name
* Age
* Email
* Contact Number
* Address

The data is stored safely without being erased on program restart.

---

## ⭐ Key Features

* **Beginner-Friendly Tkinter GUI**
* Clean and simple layout inspired by GitHub-style markdown formatting
* **Data persistence**: Records are stored and never overwritten
* Auto-incremented **record numbering** for each new submission
* Easy-to-understand file structure
* Great for students learning Tkinter and Python basics
